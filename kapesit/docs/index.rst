Welcome to KAPESIT's documentation!
================================

KAPESIT is a high-performance framework for quantum computing and artificial intelligence research. It combines optimized C++ and assembly code with Python interfaces to provide efficient implementations of quantum algorithms, numerical computations, and AI models.

Features
--------

* High-Performance Computing
    * SIMD-optimized numerical operations
    * Assembly-optimized critical paths
    * OpenMP parallel processing
    * GPU acceleration support

* Quantum Computing
    * Quantum circuit simulation
    * Quantum state evolution
    * Quantum measurement
    * Quantum entanglement
    * Quantum Fourier transform

* Numerical Methods
    * Fast matrix operations
    * Eigenvalue computation
    * SVD decomposition
    * Cholesky decomposition
    * QR decomposition
    * Fast Fourier transform

* AI and Machine Learning
    * Quantum-inspired algorithms
    * Multi-agent systems
    * Quantum reasoning
    * Neural network acceleration
